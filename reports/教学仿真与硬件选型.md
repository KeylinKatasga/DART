## 2 工具箱与建模层次

Simscape Fluids 面向泵、阀、管路、换热器等流体网络。它适合系统级物理建模，并不等于能够从任意外形直接求出外流场、涡流和表面压力的通用 CFD 求解器。[1]

Aerospace Blockset 提供航空航天运动、环境和坐标变换等模型模块；使用这些模块仍需要提供合理的力、力矩与气动数据，不能由软件自动保证模型符合实物。[2]

| 学习问题 | 优先工具 | 当前处理 |
| --- | --- | --- |
| 数值积分是否正确 | MATLAB ode45 | 提供源码与解析解检查 |
| 固定支点摆如何衰减 | 基础 ODE 或 Multibody | 已制作基础模型 |
| 管路压力与流量 | Simscape Fluids | 已找到安装文件 |
| 相机标定与位姿 | OpenCV 或视觉工具箱 | 提供官方学习资料 |
| 表面压力和流动分离 | 专用 CFD 与实验 | 不在本轮模型内 |

原路线有三点需要修正。加速度计测量的是比力；动态加速和近自由落体时不能简单把读数当成重力方向。四元数积分必须先约定旋转方向、乘法顺序和角速度所在坐标系。模型中若空气动力已包含控制面作用，便不能再把同一作用作为额外力重复加入。

“误差小于1%”也应说明分母与时间区间：解析量过零时，相对误差会失真。当前示例采用高度绝对误差、事件时间误差和能量变化检查。

## 3 已制作的首轮仿真

实验 A 为无初速度的柔性球体竖直下落。高度向上为正，状态为高度和竖直速度，重力向下，二次阻力始终与速度反向。高度下降至零时终止积分；不模拟碰撞、反弹或接触变形。

演示参数为质量 5 g、半径 35 mm、释放高度 1 m、空气密度 1.225 kg/m³、常数阻力系数 0.47、重力加速度 9.81 m/s²。这些是算法演示假设，不是对真实泡沫球的标定数据。低速阻力系数变化、浮力、表面粗糙度与形变均未建模。

实验 B 为固定支点单摆，自由度只有摆角。演示摆长 0.3 m、质量 20 g、初始摆角 15°，使用线性黏性阻尼，阻尼系数为 0.001 N·m·s/rad。只观察无驱动的自由衰减，不包含控制器。

## 4 联网资料与可复现实验

本轮检索覆盖 MathWorks、NASA、OpenMV、Raspberry Pi、OpenCV 和密歇根大学 APRIL 实验室及其官方仓库。以下是教学相关资料索引，不是飞镖主动控制案例汇编。每条资料都注明能支撑的学习任务，避免把演示视频当成经过验证的工程方案。

### 被动稳定与机械运动

NASA 的 Stabilators 页面解释尾部气动力与俯仰运动的关系，可用于区分稳定作用和操纵作用；页面的旧 Java 演示不应视为当前可直接运行的软件。仅用其概念说明，不迁移成飞镖执行机构设计。[3]

MathWorks 的 Analyze a Single Pendulum 给出单摆动力学分析流程。可复现实验是从初始偏角释放固定支点摆，比较摆角曲线及机械能变化；与本项目实验 B 的学习目标一致。[4]

MathWorks 的 Create a Simple Pendulum in MATLAB 展示用 Multibody 类构建多体系统。适合在已理解 ODE 后学习几何、关节和惯量的表达；本地 R2025b 的 API 可用性须通过版本文档核对。[5]

### 桌面姿态观测

APRIL 实验室介绍了 AprilTag 的身份识别及相对相机位姿估计。可把标签固定在桌面摆上，静止采样后比较重复测量误差；标签是人工标志物，不代表任意物体都能使用同样方法定位。[6]

AprilRobotics 官方仓库提供检测器构建和位姿接口资料。复现时记录代码版本、标记实际尺寸、相机内参和坐标约定；不要只记录“识别成功”。[7]

OpenCV PnP 文档说明由空间点和图像点求解位姿的方法。桌面实验应同时报告重投影误差与已知距离或角度误差；重投影误差小并不单独证明三维尺度正确。[8]

OpenMV AprilTag 文档给出内置检测接口。稳定版与开发版文档存在差异，代码应对应实机固件；平移量需按该版本定义和标签实测尺寸转换，不能直接把原始返回数值当成米。[9]

### 图像采集与硬件依据

Raspberry Pi 的相机文档解释滚动快门与全局快门。桌面摆动图像出现倾斜和扭曲时，应区分快门畸变与运动模糊；全局快门减少逐行时差，不会自动消除曝光期间的模糊。[10]

树莓派 5、Global Shutter Camera 和 OpenMV RT1062 的产品页用于核对具体硬件，而不是用来推断特定 AprilTag 程序的实际帧率。[11][12][13]

## 5 OpenMV 与树莓派方案选择

对于完整学习路线，优先选择桌面树莓派 5 视觉记录平台；对只想尽快完成单标签检测的入门实验，选择 OpenMV RT1062。已有任一设备时，先复用它完成标定和日志，再决定升级。这是针对教学范围的选型建议。

| 对比维度 | OpenMV RT1062 | Raspberry Pi 5 |
| --- | --- | --- |
| 官方处理器信息 | Cortex M7 600 MHz | 四核 Cortex A76 2.4 GHz |
| 主要开发方式 | MicroPython 与内置视觉 API | Linux 与 Python/C++ |
| 快速标签演示 | 集成度高 | 需配置相机和软件 |
| 多算法和日志 | 受内存及固件 API 约束 | 更适合完整数据处理 |
| 相机路径 | 模块兼容性按板卡核对 | CSI 相机与适配排线 |
| 实时性 | 仍需测量耗时和抖动 | 普通 Linux 无硬实时保证 |
| 主要系统负担 | 算法资源与版本兼容 | 电源、散热、系统维护 |

OpenMV RT1062 官方页面列有 32 MB SDRAM 和板载三轴加速度计。三轴加速度计不是含陀螺仪的六轴 IMU；若需要角速度观测，应单独核验外接传感器。官方“简单算法”帧率不能作为 AprilTag 或融合算法的帧率保证。[13]

方案 A 为 RT1062、兼容镜头或相机模块、打印标记、USB 供电和电脑记录端。适合静态测量、色块、单标签及低复杂度桌面观察。优先验收标签尺寸、距离尺度和丢帧情况，再考虑增加 IMU。

方案 B 为树莓派 5 4 GB 起步、相机、合适的排线、存储、电源及散热。4 GB 是本项目单相机教学处理的起步建议，不是对任意负载的保证。静态入门可使用已有兼容相机；需要观察摆动畸变时，再考虑 Global Shutter Camera 和另购兼容镜头。Pi 5 的官方供电规格为 5 V/5 A，并非板卡恒定功耗。[11][12]

如果后续增加桌面传感器采集，可由 MCU 负责带时间戳的 IMU 读取，树莓派负责视觉和日志。先把两路原始数据留存，再评估融合；当前不包含飞行器控制链路。

不提供未经核实的本地人民币报价。总成本应包括镜头、适配线、电源、存储、散热、安装支架、传感器和开发时间，不能仅比较裸板价格。香橙派需指定具体板卡、系统和相机后再判断，不能假设树莓派相机软件可以原样迁移。

## 6 验收方法与推进顺序

以下为建议的桌面实验验收设计，不是硬件性能承诺。两平台使用同一标签、照明、距离、分辨率和曝光条件；固定软件及固件版本，否则性能比较没有一致基础。

| 阶段 | 实验与记录 | 进入下一阶段条件 |
| --- | --- | --- |
| 数值基础 | 解析解、步长、能量检查 | 断言通过且单位清楚 |
| 静态视觉 | 多角度标定与独立测距 | 报告像素误差和尺度误差 |
| 桌面运动 | 摆动录像与漏检统计 | 能区分模糊和姿态跳变 |
| 数据时序 | 采集、处理、接收时间 | 明确时钟偏移和延迟分布 |
| 传感器融合 | 离线比较原始与融合数据 | 留出独立验证段 |

帧率至少同时记录有效检测率、帧间隔及处理耗时的中位数和第95百分位。处理耗时不等于端到端延迟；曝光、传输和排队也要计入。没有可靠采集时间戳时，应写明只能测得哪一段时间。

静态距离测试覆盖多个距离与视角，报告重复性和系统偏差；动态测试报告角度误差、异常跳变及漏检比例。不同算法应使用同一段录制数据做离线比较，减少光照和运动重复性造成的干扰。

先完成 Windows MATLAB 实际运行核验，再逐步复现官方单摆案例和相机标定。模型可复现后，再用桌面实测数据评估假设。当前仿真不具备自由飞行六自由度、气动识别、落点概率或闭环控制能力。
