## 1. 问题定义与边界条件

### 1.1 物理场景

一枚带尾翼（可有可动舵面）的飞镖，从发射机构抛出，飞行中依靠**板载 IMU + 摄像头**自主修正弹道，命中**静止地面目标**。

### 1.2 关键前提（务必先读）

| 前提 | 内容 | 影响 |
|---|---|---|
| **P1 机构完备** | 发射机构本身精度高，落点误差有界但非零 | 制导只需压掉残余误差 → 可线性化 |
| **P2 镖机分离** | 飞镖**不知道**出手初速、初姿态、初位置 | 绝对初值不可用 → 必须用相对量 |
| **P3 目标静止** | 静态靶，位置固定 | 相对运动方程简化：$\dot{\mathbf{r}}=-\mathbf{V}_d$ |
| **P4 目标有特征** | 靶面有已知尺寸的图案/标记 | 单目可估距离（关键可观测性来源）|
| **P5 尾翼可动** | 具备舵面或质心控制能力 | 否则只能"看得见改不了" |

> **P2 是整个模型的出发点**，它把问题从"弹道命中"推向"自主相对导航 + 制导"。

### 1.3 分阶段路线

```
静态靶物理框架  →  视觉制导闭环  →  加卡尔曼滤波  →  移动目标  →  自适应置信度
   （已完成）        （已完成）      （框架已定）     （待做）      （待做）
```

## 2. 坐标系与符号约定

| 坐标系 | 定义 | 用途 |
|---|---|---|
| **N 系（地面/惯性系）** | $X$ 右、$Y$ 前、$Z$ 上（右手系） | **状态估计在此系进行** |
| **W 系（机体系/体轴系）** | $x$ 沿镖轴指向镖尖，$y$ 右，$z$ 按右手系 | 传感器测量、力/力矩计算 |

**姿态表示**：四元数 $\mathbf{q}$（机↔地），满足 $\|\mathbf{q}\|=1$；等价欧拉角 $(\phi,\theta,\psi)$。

**旋转矩阵**：$R(\mathbf{q})$ 把**机体系矢量 → 地面系**；$R^T$ 反之。

> **重要工程约定**：**所有状态估计在 N 系做**（方程干净，无隐藏惯性项），W 系只用于把测量量算出来、把加速度计读数旋出去。这是用户手推稿中"非惯性系补偿力"问题的正式解法。

## 3. 刚体动力学：飞镖的闭环方程

### 3.1 完整状态（仿真真值侧，12 维）

| 符号 | 含义 | 维度 | 系 |
|---|---|---|---|
| $\mathbf{P}_d$ | 飞镖位置 | 3 | N |
| $\mathbf{V}_d$ | 飞镖速度 | 3 | N |
| $\mathbf{q}$ | 姿态 | 3（有效） | N↔W |
| $\boldsymbol\omega$ | 角速度 | 3 | W |

靶点 $\mathbf{P}_t$ 为**常量参数**，不是状态。

### 3.2 平动动力学

$$
m\big(\dot{\mathbf{v}} + \boldsymbol\omega\times\mathbf{v}\big) = \mathbf{F}_{aero} + \mathbf{F}_g
$$

气动力在机体系的分量（小攻角线性化）：

| 分量 | 来源 | 表达式 |
|---|---|---|
| $a_x$（沿轴）| 阻力 | $-q_\infty S C_{D0}/m$ |
| $a_y$（侧向）| 侧滑角 $\beta$ | $+q_\infty S C_{Y\beta}\,\beta/m$ |
| $a_z$（法向）| 攻角 $\alpha$ | $-q_\infty S C_{N\alpha}\,\alpha/m$ |

动压 $q_\infty=\tfrac12\rho V^2$。

### 3.3 转动动力学（含陀螺项）

$$
I\dot{\boldsymbol\omega} + \boldsymbol\omega\times(I\boldsymbol\omega) = \mathbf{M}_{aero}
$$

**尾翼提供静稳定力矩**（恢复）与气动阻尼：

$$
M_\alpha = \frac{\partial M}{\partial\alpha} < 0,\qquad M_q = \frac{\partial M}{\partial q} < 0
$$

俯仰运动退化为**带阻尼二阶振子**：

$$
\omega_n = \sqrt{\frac{-M_\alpha}{I_{yy}}},\qquad
\zeta = \frac{Z_\alpha/(mV) - M_q/I_{yy}}{2\omega_n}
$$

### 3.4 陀螺耦合与复攻角方程（核心结果）

定义**复攻角** $\zeta = \beta + i\alpha$，横向-纵向耦合可合并为单一复方程：

$$
\boxed{\ \ddot\zeta + (D - i\,\omega_p)\,\dot\zeta + \omega_s^2\,\zeta = 0\ }
$$

| 符号 | 含义 |
|---|---|
| $\omega_s^2 = -M_\alpha/I_t$ | 风标（静稳定）频率平方 |
| $D = -M_q/I_t$ | 气动阻尼 |
| $\omega_p = p$ | 进动率（= 滚转率）|

**解的结构**：两个复频率 → **章动（nutation，快，频率 $\omega_s$）+ 进动（precession，慢，速率 $\omega_p$）**，二者均以 $e^{-Dt/2}$ 衰减。

**稳定性判据**：

$$
\boxed{\ D>0\ \text{且}\ \omega_s^2>0\ }
$$

> **重要结论**：陀螺耦合项 $\omega_p$ **不改变稳定性**，只把"平面摆动"变成"螺旋章动"。飞镖自旋不会更稳或不稳（区别于子弹的陀螺稳定）。

### 3.5 闭环性质

飞镖姿态-攻角构成**负反馈自动控制系统**：

```
姿态 → 气动力 → 地面加速度 → 地面速度 → (旋回机体) → 攻角/侧滑角 → 恢复力矩 → 姿态
```

**控制目标不是 $\alpha\to0$，而是 $\alpha\to\alpha_{trim}$（配平）**，配平值由重力平衡决定。

## 4. 尾翼的物理作用：只修方向，不修速度

### 4.1 核心结论

$$
\boxed{\text{尾翼}:\ \text{改变速度矢量方向 }\hat{\mathbf{V}}\text{，几乎不改变大小 }|\mathbf{V}|}
$$

**物理依据**：

- 法向力 $\mathbf{F}_\perp\perp\mathbf{V}$ → 转动速率 $\dot{\Theta}=F_\perp/(mV)$
- 改变大小只能靠**阻力**（方向固定反向于速度，**不可控**）
- 转方向的"杠杆"是 $1/(mV)$，**成本远低于变速，且变速原理上不可控**

### 4.2 定量对比（示例：$V=20$ m/s，$t=1$ s，偏差 0.35 m）

| 手段 | 所需量 | 可行性 |
|---|---|---|
| 修方向 | $\Delta\Theta\approx1°$ | ✅ 尾翼轻松做到 |
| 修大小 | $\Delta V\approx0.35$ m/s | ❌ 无法产生可控轴向力 |

### 4.3 但要区分"控制层"与"决策层"（易混淆点）

| 层面 | 内容 | 需要速度估计吗 |
|---|---|---|
| **控制层** | 尾翼只改方向 | — |
| **决策层** | 预测落点、算修正量、算 $t_{go}$ | **必须，且精度直接决定命中** |

> **澄清**：说"只修方向"不等于"不需要速度估计"。**控制可以简化，估计不能简化。** 制导律 $a_{cmd}=NV\dot\lambda$ 里 $V$ 必须可信，否则落点预测、$t_{go}$、增益调度全部失真。

### 4.4 修正的隐性代价（不可理想化）

1. **内环滞后**：尾翼偏转 → 姿态回路 → 实际法向力，时间常数 $\tau$
2. **诱导阻力**：$C_D = C_{D0} + kC_L^2$，转得越猛，阻力越大
3. **章动耦合**：高增益制导会激发俯仰章动

## 5. 状态量定义：最小充分状态集

### 5.1 相对位置定义（绕开初值的关键）

$$
\mathbf{r} \equiv \mathbf{P}_t - \mathbf{P}_d
$$

**静态靶时运动学耦合**：

$$
\dot{\mathbf{r}} = -\mathbf{V}_d
$$

> **估出 $\mathbf{r}$ 的导数就等于估出了 $\mathbf{V}_d$** —— 目标状态与自身状态不是两个独立问题，而是一个耦合的估计问题。

### 5.2 估计状态向量（19 维）

$$
\boxed{\ \hat{\mathbf{x}} = \big[\ \mathbf{r}_{(3)},\ \mathbf{V}_d{}_{(3)},\ \mathbf{q}_{(4)},\ \boldsymbol\omega_{(3)},\ \mathbf{b}_a{}_{(3)},\ \mathbf{b}_g{}_{(3)}\ \big]^T\ }
$$

| 分量 | 含义 | 为何必须估 |
|---|---|---|
| $\mathbf{r}$ | 目标相对位置 | 制导方向基准 + 距离 |
| $\mathbf{V}_d$ | 自身速度 | 预测落点、算 $t_{go}$、算过载指令 |
| $\mathbf{q}$ | 姿态 | 旋转 IMU 测量、算视线机体系投影 |
| $\boldsymbol\omega$ | 角速度 | 姿态传播、内环反馈 |
| $\mathbf{b}_a$ | 加速度计零偏 | IMU 漂移主因 |
| $\mathbf{b}_g$ | 陀螺零偏 | 姿态漂移主因 |

**有效维度**：$3+3+3+3+3+3=18$（四元数归一化约束减 1）。

### 5.3 可观测性一览

| 状态 | 可观测性 | 来源 |
|---|---|---|
| $\mathbf{r}$ 方向 | ✅ 直接 | 摄像头 |
| $\mathbf{r}$ 距离 $\|\mathbf{r}\|$ | ⚠️ 弱 | 目标已知特征尺寸 + 运动视差 |
| $\mathbf{V}_d$ 方向 | ⚠️ 间接 | IMU 积分 + 视觉校正 |
| $\mathbf{V}_d$ 大小 | ⚠️ 弱 | 滤波收敛 |
| $\mathbf{q}$ 俯仰/滚转 | ✅ | 加速度计测重力方向 |
| $\mathbf{q}$ 偏航 | ⚠️ | 需视觉补 |
| $\boldsymbol\omega$ | ✅ | 陀螺直接给 |
| $\mathbf{b}_a,\mathbf{b}_g$ | ❌ | 在线标定（需观测运动）|

**两大核心难点**：

$$
\boxed{\text{速度大小 }|\mathbf{V}_d|\quad\text{和}\quad\text{相对距离 }\|\mathbf{r}\|}
$$

> **二者均非直接可测，只能靠"运动过程中观测的变化"反推** → 飞镖必须动起来（有视差）才能收敛估计。

## 6. 传感器能力边界（IMU）

### 6.1 直接测量量

| 传感器 | 测量 | 模型 |
|---|---|---|
| **陀螺仪** | 角速度（机体系） | $\boldsymbol\omega_m = \boldsymbol\omega + \mathbf{b}_g + \mathbf{n}_g$ |
| **加速度计** | **比力**（非重力加速度） | $\mathbf{f}_m = R^T(\mathbf{a}-\mathbf{g}) + \mathbf{b}_a + \mathbf{n}_a$ |

> **关键概念**：加速度计测的是**比力（specific force）**，即"除重力外的所有加速度"。静止时读数 $\ne 0$（读的是重力反作用）。

### 6.2 积分才能得到的量

| 目标量 | 方法 | 需要的初值 | 误差增长 |
|---|---|---|---|
| 姿态 $\mathbf{q}$ | $\dot{\mathbf{q}}=\frac12\mathbf{q}\otimes[0,\boldsymbol\omega_m]$ | $\mathbf{q}_0$ | $\sim t$（线性）|
| 速度 $\mathbf{V}$ | $\dot{\mathbf{V}}=R(\mathbf{q})(\mathbf{f}_m-\mathbf{b}_a)+\mathbf{g}$ | $\mathbf{V}_0$ | $\sim t$（常值加速度计零偏）|
| 位置 $\mathbf{P}$ | $\dot{\mathbf{P}}=\mathbf{V}$ | $\mathbf{P}_0$ | $\sim t^2$（常值加速度计零偏）|

### 6.3 能力边界总表

| 量 | IMU 能否给 | 原因 |
|---|---|---|
| 三轴角速度 | ✅ | 陀螺本职 |
| 三轴比力/加速度 | ✅ | 加速度计本职 |
| 姿态（俯仰/滚转）| ✅ | 准静态时重力方向提供绝对基准 |
| **姿态（偏航）** | ❌ | 绕重力轴旋转，重力不变，无信息 |
| 速度方向 | ⚠️ 短时可靠 | 积分，长时漂移 |
| **速度大小** | ⚠️ | 同上，且**匀速不可感知**（伽利略相对性）|
| 绝对位置 | ❌ | 二次积分漂移爆炸 |
| 重力方向 | ✅ | 静态直接读 |
| 磁北方向 | ❌ | 需磁力计 |

### 6.4 IMU 单独不可用的两个根本原因

**原因 1：需要初值，而初值因 P2（镖机分离）不可知**

$$
\mathbf{V}(t)=\mathbf{V}_0+\int_0^t\mathbf{a}\,dt,\qquad \mathbf{P}(t)=\mathbf{P}_0+\int_0^t\mathbf{V}\,dt
$$

**原因 2：零偏导致无界漂移**

$$
\delta V(t)\approx b_a t,\qquad \delta P(t)\approx\tfrac12 b_a t^2
$$

消费级 IMU（$b_a\sim0.05$ m/s²）飞 5 秒 → $\delta P\approx0.6$ m，**平方级增长，直接失准**。若误差主要来自陀螺零偏引起的重力投影误差，位置误差才可能出现近似立方项。

### 6.5 加速度计能否提供初值？（专项结论）

| 初值类型 | 加速度计能否给 | 条件 |
|---|---|---|
| 姿态（俯仰/滚转）| ✅ | 需准静态（$\mathbf{a}=0$）|
| 姿态（偏航）| ❌ | 重力轴旋转不可测 |
| 速度初值 | ❌ | 原理性：测不出匀速 |
| 位置初值 | ❌ | 二次积分 |

$$
\boxed{\text{加速度计给不了速度/位置初值——这是伽利略相对性的直接后果}}
$$

## 7. 传感器能力边界（视觉）

### 7.1 摄像头提供什么

**单目摄像头输出目标在像平面的位置** $(u,v)$，标定后换算为**视线角**：

$$
\lambda_y=\arctan\frac{u-u_c}{f},\qquad \lambda_z=\arctan\frac{v-v_c}{f}
$$

$f$ 为焦距（已知），$(u_c,v_c)$ 为主点。

**观测方程**（机体系下目标方向）：

$$
\mathbf{z}_{cam} = \frac{R^T\mathbf{r}}{\|R^T\mathbf{r}\|} + \mathbf{n}_{cam}
$$

> 单位矢量只有 **2 个独立分量** —— 单目只能给出**方向**，**给不了距离**。

### 7.2 距离的获取途径（关键）

$$
\|\mathbf{r}\| = \frac{f\cdot W_{real}}{w_{pixel}}\quad(\text{已知特征尺寸})
$$

- **途径 A**：目标已知特征尺寸（**依赖前提 P4**）
- **途径 B**：运动视差（飞镖移动时方向变化率与距离耦合，滤波收敛）
- **途径 C**：重力方向约束（辅助）

> **P4"目标有特征"是让距离从"不可观测"变为"可观测"的关键前提。**

### 7.3 像素偏移率的双用途

**用户洞察**：像素点偏移可直接给出**视线角速率**，且**不需要距离**。

$$
\Delta\lambda = \arctan\frac{\Delta u}{f}\ \Rightarrow\ \dot\lambda \approx \frac{\lambda_k-\lambda_{k-1}}{\Delta t}
$$

**PN 制导的主体输入正是 $\dot\lambda$** —— 这是传统导引头（红外/电视）的经典做法。

**但有两个必须注意的坑**：

**坑 1：像素偏移 ≠ 镖轴偏移**

| 你的目标 | 像素偏移实际给出 |
|---|---|
| 镖轴相对目标方向的偏差 $\angle(\hat{\mathbf{V}},-\hat{\mathbf{r}})$ | 视线角速率 $\dot\lambda$（目标在视野中的移动速度）|

**反例**：飞镖速度矢量恰好指向目标时，像点**完全不动**（$\dot\lambda=0$），**无论姿态多歪**。所以"像素不动 ≠ 镖轴对准"。

**坑 2：像素偏移被自身角速度污染（视线稳定问题）**

$$
\dot{\boldsymbol\lambda}_{pixel} = \underbrace{\dot{\boldsymbol\lambda}_{true}}_{\text{真实视线运动}} + \underbrace{\boldsymbol\omega}_{\text{飞镖自身转动}}
$$

分离需要陀螺：

$$
\boxed{\ \dot{\boldsymbol\lambda}_{true} = \dot{\boldsymbol\lambda}_{pixel} - \boldsymbol\omega_{gyro}\ }
$$

> **所以：不需要距离，但需要陀螺来"稳定视线"。**

### 7.4 "不需要距离"的准确含义

用户表述："从距离驱动转换成比例驱动，某种意义上算拉普拉斯变换"。

**精确化**：

| 层面 | 判断 |
|---|---|
| $\dot\lambda$ 可直接驱动 PN 制导 | ✅ 成立 |
| "不需要距离" | ✅ 但 = 把 $r,V$ **吸收进固定增益**（信息有损）|
| 增益调度 | ❌ 需要 $t_{go}=r/V$ |
| "拉普拉斯变换"命名 | ❌ 应为**球面投影 / 参数吸收** |

**为什么不是拉普拉斯变换**：拉普拉斯是"线性积分变换、可逆、无损"；这里是"把 $r/V$ 吸收进常值增益"，是**降维近似**，信息有损。

**更贴切的数学图像**：把状态从 $\mathbb{R}^3$（位置）投影到 $S^2$（方向单位球）—— 在这个球面上做追踪，距离被消掉：

$$
\mathbb{R}^3 \ni \mathbf{r} \xrightarrow{\ \text{归一化投影}\ } \hat{\mathbf{r}}\in S^2
$$

这是**几何投影**，不是积分变换。

## 8. 估计器：EKF 框架与用户手推稿的对应

### 8.1 用户手推稿解读与判定

| 手推稿内容 | 解读 | 判定 |
|---|---|---|
| 双系 N（惯性）+ W（固有/非惯性）| N 做基准，W 做机体系 | ✅ 正确框架 |
| $\mathbf{p}=\mathbf{r}_T-\mathbf{r}_s$，$\dot{\mathbf{p}}=\dot{\mathbf{r}}_T-\dot{\mathbf{r}}_s$ | **相对状态** | ✅ 与 §5.1 一致 |
| $\ddot{\mathbf{p}}=\mathbf{a}_T-\mathbf{a}_s$ | 相对加速度 | ✅ 核心 |
| $\dot{X}_t^N=\begin{bmatrix}0&1\\0&0\end{bmatrix}X_t^N+\begin{bmatrix}-a_s\\0\end{bmatrix}+\begin{bmatrix}0\\n\end{bmatrix}$ | **匀速(CV)模型 + 自身加速度作控制输入** | ✅ 标准写法 |
| 把 IMU 加速度作为**控制输入**而非噪声 | 完整利用 IMU 信息，不被滤波 average 掉 | ✅ 内行处理 |
| 视角 $\theta=\arctan(p_y/p_x)$，$L=\|\mathbf{p}\|$ | 方位角 + 距离 | ✅ 方向正确；距离有前提（§7.2）|
| "坐标误差大，量测噪声小" | 姿态/坐标变换误差 > 像素噪声 | ✅ 优先级判断正确 |
| "非惯性系下的补偿力" | 意识到 W 系含惯性力 | ✅ 直觉正确 |

### 8.2 三个必须打的补丁

#### 补丁一（致命）：加速度计给的不是 $\mathbf{a}_s$

$$
\mathbf{f}_m = R^T(\mathbf{a}_s-\mathbf{g})\ \Rightarrow\ \mathbf{a}_s = R\mathbf{f}_m + \mathbf{g}
$$

飞镖自由飞行时加速度计读数**只剩气动力加速度**。严格相对动力学：

$$
\ddot{\mathbf{p}} = \underbrace{\mathbf{a}_T}_{\approx0} - \big(R\mathbf{f}_m+\mathbf{g}\big)
$$

> **重力项不会抵消**：靶被地面支撑（法向力抵消重力），飞镖自由飞行。
> **若直接把 $\mathbf{f}_m$ 当 $\mathbf{a}_s$ 用，注入恒定虚假加速度 $9.8\ \text{m/s}^2$，飞 1 秒位置预测错约 4.9 m** —— 直接从"打靶"变成"打偏一个房间"。
>
> **正确做法**：进滤波器的控制输入必须是 $-\big(R\hat{\mathbf{q}}\,\mathbf{f}_m+\mathbf{g}\big)$，姿态 $R$ 用陀螺积分。

#### 补丁二：W 系方程不成立，除非加"隐藏项"

转动坐标系中的导数需用**输运定理**：

$$
\frac{d}{dt}\big(R^T\mathbf{p}_N\big) = R^T\dot{\mathbf{p}}_N - \boldsymbol\omega\times\mathbf{p}_W
$$

另有角加速度项 $\dot{\boldsymbol\omega}\times\mathbf{p}$、向心项 $\boldsymbol\omega\times(\boldsymbol\omega\times\mathbf{p})$。

> **工程建议**：**状态估计全部放 N 系做**（方程原样，零隐藏项），W 系只用来（a）算量测方位角、（b）把 $\mathbf{f}_m$ 旋出去。即：
> $$\text{估计在 } N,\quad \text{测量在 } W,\quad R(\hat{\mathbf{q}})\text{ 做桥}$$
> 姿态误差 $\delta\mathbf{q}$ 同时污染**重力补偿**与**量测旋转**，所以 $\mathbf{q},\mathbf{b}_a,\mathbf{b}_g$ 必须进状态。

#### 补丁三：观测方程要写全，$L$ 有前提

$$
\mathbf{z}=h(\hat{\mathbf{x}})=\begin{bmatrix}\mathrm{atan2}\big((R^T\hat{\mathbf{p}})_y,\ (R^T\hat{\mathbf{p}})_x\big)\\[4pt] \hat{L}_{feat}\end{bmatrix},\qquad
\hat{L}_{feat}=\frac{f\,W_{real}}{w_{pixel}}
$$

- 预测量测时必须**先旋到机体系再取 arctan**
- $L$ 依赖已知特征尺寸；缺之则 $\|\mathbf{p}\|$ 弱可观测，$t_{go}$ 估不准

### 8.3 离散化（EKF 用）

取步长 $\Delta t$：

$$
\Phi = e^{A\Delta t}=\begin{bmatrix}1&\Delta t\\0&1\end{bmatrix},\qquad
B_\Delta=\begin{bmatrix}-\Delta t^2/2\\-\Delta t\end{bmatrix},\qquad
Q = q\begin{bmatrix}\Delta t^3/3&\Delta t^2/2\\\Delta t^2/2&\Delta t\end{bmatrix}
$$

### 8.4 EKF 迭代

$$
\begin{aligned}
\text{预测：}\quad & \hat{\mathbf{x}}^-=f(\hat{\mathbf{x}}^+,\ \text{IMU}),\quad P^-=FP^+F^T+Q\\
\text{更新：}\quad & K=P^-H^T(HP^-H^T+R)^{-1}\\
& \hat{\mathbf{x}}^+=\hat{\mathbf{x}}^-+K(\mathbf{z}-h(\hat{\mathbf{x}}^-))
\end{aligned}
$$

- $Q$：IMU 噪声（驱动预测不确定性增长）
- $R$：摄像头噪声（**远距离 $R$ 大 → 信任 IMU；近距离 $R$ 小 → 信任视觉**）
- **$R$ 的调度 = "置信度调整"**

### 8.5 为何不需要绝对初值（核心洞察）

制导方程只含**相对量**：

$$
r\ddot\lambda + 2\dot r\dot\lambda = -a_{cmd}\cos(\cdot)
$$

只含 $r,\dot r,\lambda,\dot\lambda$。**初值 $\lambda_0,\dot\lambda_0$ 由制导启动时刻的观测给出，无需绝对位置/速度。**

$$
\boxed{\text{飞镖不需要知道"从哪、以什么姿态、什么速度出发"，只需在制导开始时观测到 $(\lambda_0,\dot\lambda_0)$}}
$$

**剩余的真实困难**：
1. **制导启动时的截获（acquisition）**：出手后姿态未定，需解决"何时/如何锁定目标"
2. **距离不可直接观测**（除非用 P4 特征尺寸或运动视差）

## 9. 制导律：两条技术路线

### 9.1 共同基础：比例导引（PN）

$$
\mathbf{a}_{cmd}=N\,\mathbf{V}_d\times\dot{\boldsymbol\lambda}\quad\Longleftrightarrow\quad a_{cmd}=N\,V\,\dot\lambda
$$

**收敛性**（小角度、理想内环）：

$$
\dot\lambda(t)=\dot\lambda_0\left(1-\frac{t}{t_{go}}\right)^{N-2}\ \xrightarrow{\ t\to t_f\ }\ 0
$$

- $N>2$：$\dot\lambda\to0$，末端沿直线撞向目标，脱靶量→0
- **$N$ 越大收敛越快，但对噪声越敏感**

**脱靶量估计**：

$$
\text{Miss}\sim\frac{r_0|\dot\lambda_0|\,t_{go}}{N-1}\cdot f(\tau)
$$

**命中条件（几何）**：

$$
\angle\big(\hat{\mathbf{V}},-\hat{\mathbf{r}}\big)=0\quad\text{且}\quad\|\mathbf{r}\|\to0
$$

### 9.2 路线 A：距离驱动（EKF 全程）

| 项 | 内容 |
|---|---|
| 观测量 | 方位 + 距离 |
| 估计负担 | 重（19 维 EKF）|
| 增益调度 | ✅ 可（$t_{go}$ 自适应）|
| 噪声敏感性 | 低（滤波器平滑）|
| 适用 | 全程制导、要精度 |

**制导量提取**：

| 制导量 | 表达式 | 用到的估计 |
|---|---|---|
| 视线单位矢量 | $\hat{\mathbf{r}}=\mathbf{r}/\|\mathbf{r}\|$ | $\mathbf{r}$ |
| 视线角速率 | $\dot{\boldsymbol\lambda}=\dfrac{\mathbf{r}\times(-\mathbf{V}_d)}{\|\mathbf{r}\|^2}$ | $\mathbf{r},\mathbf{V}_d$ |
| 剩余飞行时间 | $t_{go}=\dfrac{\|\mathbf{r}\|}{\|\mathbf{V}_d\|\cos\theta}$ | $\mathbf{r},\mathbf{V}_d$ |
| 过载指令 | $a_{cmd}=N V_d\dot\lambda$ | $V_d$ 大小、$\dot\lambda$ |

### 9.3 路线 B：比例驱动（纯角度）

| 项 | 内容 |
|---|---|
| 观测量 | 只需像素偏移率 $\dot\lambda$ |
| 估算负担 | 轻（几乎无估计器）|
| 增益调度 | ❌ 固定，末段会钝 |
| 噪声敏感性 | **高（微分放大 $\propto1/\Delta t$）** |
| 适用 | 中段修正、简单实现 |

**注意**："不需要距离"= 把 $r,V$ 藏进常值增益 $K$，**信息有损**。

### 9.4 工程推荐：混合方案

```
中段：比例驱动（轻量、够用、不需要距离估计）
  ↓ 交接
末段：距离驱动（准、能收，加增益调度与冻结策略）
```

这正是真实导引头的**中制导/末制导交接**思想。

### 9.5 制导律的约束条件（不可理想化）

1. **内环滞后** $\tau$：舵机 + 姿态回路，一阶滞后 $\tau\dot a+a=a_{cmd}$
2. **末段角速率爆炸**：$r\to0$ 时 $\dot\lambda$ 发散 + 噪声放大 → 需**冻结修正**或降增益
3. **时标分离**：外环带宽 ≪ 内环带宽，否则耦合震荡

## 10. 误差预算与传感器选型

### 10.1 核心误差公式

$$
\sigma_{\dot\lambda}=\frac{\sqrt2\,\sigma_\lambda}{\Delta t}
$$

- **高帧率** → 压微分噪声（但曝光时间↓ → 单帧噪声↑）
- **高精度摄像头** → 压单帧角度噪声

**散粒噪声极限下的耦合**：

$$
\sigma_\lambda\propto\frac{1}{\sqrt{\Phi\,\Delta t_{exp}}}\ \Rightarrow\ \sigma_{\dot\lambda}\propto\frac{1}{\Delta t^{3/2}}
$$

> **盲目提帧率收益会被曝光不足吃掉 → 存在最优帧率，不是越快越好。**

### 10.2 误差源预算表（待填充实测参数）

| 误差源 | 表达式 | 影响环节 |
|---|---|---|
| 像素量化/散粒噪声 | $\sigma_\lambda/\Delta t$ | $\dot\lambda$ 噪声 |
| 陀螺 ARW | $\text{ARW}\sqrt{BW}$ | 视线稳定 |
| 图像延迟 | $\dot\lambda\tau_d$ | 制导指向（**不随帧率改善**）|
| 姿态偏差 | $\delta\mathbf{q}$ 耦合 | 重力补偿 + 量测旋转 |
| 距离估计误差 | $W_{real}$/视差误差 | 增益调度、$t_{go}$ |

### 10.3 传感器选型准则

| 指标 | 目标 | 理由 |
|---|---|---|
| 摄像头帧率 | ≥100 Hz（中段）| $\sigma_{\dot\lambda}\propto1/\Delta t$ |
| 曝光 | 保证信噪比，勿为帧率牺牲 | 散粒噪声极限 |
| 分辨率/FOV | 平衡（**FOV 必须能截获目标**）| 视场丢失比噪声更致命 |
| **图像延迟** | 越小越好 | **架构问题，换传感器不解决** |
| **陀螺 ARW** | 低（角随机游走）| 直接进 $\dot\lambda$ |
| 陀螺带宽 | ≥500 Hz | 视线稳定要够快 |
| **跟踪滤波器** | 卡尔曼 / $\alpha$-$\beta$ 跟踪器 | **性价比最高：同时改善噪声与延迟** |

> **关键提醒**：与其硬件死磕，**好的跟踪滤波器通常性价比高得多** —— 它同时改善噪声和延迟（可外推补延迟）：
> $$\hat{\lambda}(t+\tau_d)=\text{多项式外推 / 卡尔曼预测}$$
> **这才是"比例驱动"路线的真正技术核心。**

### 10.4 完整需求（四项缺一不可）

$$
\boxed{\text{高帧率} + \text{低噪声} + \text{低延迟} + \text{低 ARW 陀螺}}
$$

## 11. 关键结论清单

### 物理机理

1. **尾翼 = 风标稳定**：让镖轴追随速度矢量，静稳定裕度 $\text{SM}>0$ 才不翻滚。
2. **陀螺耦合不破坏稳定性**（$D>0,\omega_s^2>0$ 即可稳定），只把点头变成章动+进动。
3. **尾翼只修速度方向，不修速度大小**（变速不可控）；但**决策层必须估计速度**。
4. **配平攻角 $\alpha_{\mathrm{trim}}\ne 0$**：稳态时重力低头趋势被恢复力矩平衡。

### 状态与可观测性

5. **最小充分状态** = 相对位置 + 自身速度 + 姿态 + 角速度 + 双零偏（19 维）。
6. **相对量绕开初值**：制导只需 $(\lambda_0,\dot\lambda_0)$，不需绝对初值。
7. **两大不可直接测量**：速度大小 $|\mathbf{V}_d|$、相对距离 $\|\mathbf{r}\|$ —— 靠视差/特征尺寸收敛。

### 传感器

8. **IMU 给加速度（比力）和角速度**，速度必须积分且需初值 → 单独不可用。
9. **加速度计给不了速度/位置初值**（伽利略相对性），只给姿态（俯仰/滚转）。
10. **重力补偿不可漏**：$\mathbf{a}_s=R\mathbf{f}_m+\mathbf{g}$，漏掉 = 注入 9.8 m/s² 虚假加速度。
11. **像素偏移给 $\dot\lambda$，不是镖轴偏移**；且被自身角速度污染，**需陀螺稳定视线**。

### 制导

12. **命中 = 速度矢量与视线重合**（$\hat{\mathbf{V}}\parallel-\hat{\mathbf{r}}$），PN 通过 $\dot\lambda\to0$ 实现。
13. **"不需要距离"= 参数吸收（有损）**，不是拉普拉斯变换，而是**球面投影**。
14. **两条路线**：距离驱动（准、重）、比例驱动（轻、怕噪声）→ **中末段混合最优**。
15. **末段必须特殊处理**：角速率爆炸 + 噪声放大 → 冻结或降增益。

### 工程

16. **传感器四要素**：高帧率 + 低噪声 + 低延迟 + 低 ARW 陀螺。
17. **跟踪滤波器是性价比之王**：同时压噪声、补延迟。
18. **延迟是架构问题**，换传感器解决不了。
